# Family Shield — Week 13 prototype

A Spanish-language family preparedness flow: pause before paying, verify through a separate known channel, and use a Protocol Only fallback when independent confirmation is unavailable.

## Run locally
~~~bash
npm install
npm run dev
~~~

## Safety boundary
This prototype does not detect deepfakes, authenticate callers, certify emergencies, access contacts or messages, process or block payments, or store personal family data. It logs anonymous event types and timestamps locally in the browser only. All demo content is fictional.

See docs/PACKET.md for the product packet and docs/TEST_PLAN.md for validation requirements.
