# Family Shield — Week 13 prototype

A Spanish-language family preparedness flow: pause before paying, check through a separate known channel, and use the fallback “No se pudo comprobar. Mantén la pausa.” when independent confirmation is unavailable.

## Live prototype
https://family-rehearsal.vercel.app

## Source repository
https://github.com/reginabuilds/family-rehearsal

## Run locally
~~~bash
npm install
npm run dev
~~~

## Safety boundary
This prototype does not detect deepfakes, authenticate callers, certify emergencies, access contacts or messages, process or block payments, or store personal family data. It logs anonymous event types and timestamps locally in the browser only. All demo content is fictional.
